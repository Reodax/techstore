# TechStore

Интернет-магазин компьютерных комплектующих и готовых сборок.

## Описание

TechStore - это современный веб-сайт для покупки компьютерных комплектующих, включая процессоры, видеокарты, оперативную память, материнские платы и многое другое.

## Функции

- Каталог товаров
- Корзина покупок
- Личный кабинет пользователя
- История заказов
- Админ-панель

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage для хранения данных

## Структура проекта

- `index.html` - главная страница
- `cart.html` - корзина
- `profile.html` - профиль пользователя
- `admin.html` - админ-панель
- `css/` - стили
- `js/` - JavaScript файлы
