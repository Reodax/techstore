# Быстрое решение проблемы с правами доступа Firestore

## Проблема:
Ошибка "Missing or insufficient permissions" при добавлении администраторов.

## Решение (5 минут):

### Шаг 1: Откройте Firebase Console
1. Перейдите на: https://console.firebase.google.com
2. Войдите в свой аккаунт Google
3. Выберите проект **techstore-reodax**

### Шаг 2: Откройте Firestore Database
1. В левом меню найдите **Firestore Database** (или **База данных Firestore**)
2. Нажмите на него

### Шаг 3: Откройте вкладку Rules (Правила)
1. Вверху страницы найдите вкладки: **Data**, **Rules**, **Indexes**, **Usage**
2. Нажмите на вкладку **Rules**

### Шаг 4: Замените правила
1. Удалите все существующие правила
2. Скопируйте и вставьте следующие правила:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Правила для коллекции config (администраторы)
    match /config/{document} {
      allow read, write: if request.auth != null;
    }
    
    // Правила для коллекции users
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    
    // Правила для всех остальных коллекций
    match /{document=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null;
    }
  }
}
```

### Шаг 5: Опубликуйте правила
1. Нажмите кнопку **Publish** (Опубликовать) вверху справа
2. Подождите несколько секунд, пока правила применятся

### Шаг 6: Проверьте работу
1. Вернитесь на страницу админ-панели
2. Обновите страницу (F5)
3. Попробуйте добавить администратора снова

---

## ⚠️ Важно:

Эти правила разрешают **всем авторизованным пользователям** читать и писать данные. Это подходит для тестирования, но для продакшена нужно настроить более строгие правила.

## Для продакшена используйте правила из файла FIRESTORE_RULES.md

---

## Если не работает:

1. Убедитесь, что вы вошли в аккаунт на сайте
2. Проверьте, что правила действительно опубликованы (должна быть зеленая галочка)
3. Обновите страницу админ-панели
4. Откройте консоль браузера (F12) и проверьте, нет ли других ошибок
