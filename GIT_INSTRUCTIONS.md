# Инструкция по загрузке проекта на GitHub

## Шаг 1: Инициализация Git репозитория

Откройте терминал (PowerShell) в папке проекта и выполните:

```bash
git init
```

## Шаг 2: Добавление всех файлов

```bash
git add .
```

## Шаг 3: Первый коммит

```bash
git commit -m "Добавлена система админ-панели с проверкой доступа по email"
```

## Шаг 4: Создание репозитория на GitHub

1. Зайдите на [GitHub.com](https://github.com)
2. Нажмите кнопку **"New"** или **"+"** → **"New repository"**
3. Введите название репозитория (например: `techstore`)
4. Выберите **Public** или **Private**
5. **НЕ** ставьте галочки на "Initialize with README" (у нас уже есть файлы)
6. Нажмите **"Create repository"**

## Шаг 5: Подключение к удаленному репозиторию

После создания репозитория GitHub покажет вам команды. Обычно это:

```bash
git remote add origin https://github.com/ВАШ_НИКНЕЙМ/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
```

Например:
```bash
git remote add origin https://github.com/seriy/techstore.git
```

## Шаг 6: Загрузка на GitHub

```bash
git branch -M main
git push -u origin main
```

## Последующие обновления

Когда вы внесете изменения и захотите обновить репозиторий:

```bash
git add .
git commit -m "Описание изменений"
git push
```

## Полезные команды

- `git status` - посмотреть статус изменений
- `git log` - посмотреть историю коммитов
- `git remote -v` - проверить подключенные удаленные репозитории

---

**Важно:** В файле `js/firebase-config.js` содержатся ваши Firebase ключи. 
Если репозиторий публичный, рассмотрите возможность использования переменных окружения или .env файла.
